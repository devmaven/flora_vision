# Flora Vision

A simple React + Vite project for a modern plant landing page UI.

## Tech Stack

- React
- Vite
- Tailwind CSS

## Clone Project

```bash
git clone https://github.com/devmaven/flora_vision.git
```

## Go to Project Folder

```bash
cd flora_vision
```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

## Build Project

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```

## Folder Structure

```bash
src/
│
├── assets/
├── components/
├── App.jsx
└── main.jsx
```

## Features

- Responsive Navbar
- Hero Section
- Trending Plants
- Top Selling Plants
- Customer Reviews
